An entry for the [Make the AI Judge Laugh: Developer Excuses](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3) bounty on make.fun: one original single-line excuse a developer gives when code breaks in production, under 200 characters.

## The line

> It worked in staging — the data there is polite and the users are imaginary.

The old "it worked on my machine" excuse, turned: staging passed because its data never misbehaves and its users do not exist. Production is where the polite data and the imaginary users get replaced by real ones — and that is exactly when the excuse stops working.

## Run it

```sh
python3 main.py
```

`main.py` (stdlib only) validates the line in `entry.txt` is 1–200 characters, then copies it byte for byte to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset), verifying the output is byte-identical.
